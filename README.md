# Currency Converter GUI

**Автор:** [Рязанова Кира]

## Описание
Простое приложение для конвертации валют с использованием актуальных курсов API и сохранением истории запросов.

## Как получить API-ключ
1. Перейдите на сайт [exchangerate-api.com](https://exchangerate-api.com).
2. Введите свой Email и нажмите "Get Free Key".
3. Подтвердите почту и скопируйте ваш персональный API Key.
4. Вставьте ключ в переменную `API_KEY` в файле `main.py`.

## Использование
1. Запустите `python main.py`.
2. Выберите валюты (например, USD -> RUB).
3. Введите сумму.
4. Нажмите кнопку конвертации. Результат появится на экране и сохранится в истории.

## Тестирование
- **Положительный тест:** Ввод "100" при USD -> EUR должен выдать корректное значение.
- **Негативный тест:** Ввод "-50" или "abc" вызовет окно с ошибкой.
